# Steven Matrix

Static GitHub Pages portal for Steven Wang's websites, social media portals, podcasts, communities, and collaboration links.

## Files

- `index.html` contains the page content and JSON-LD structured data.
- `assets/styles.css` contains the responsive design system.
- `assets/app.js` powers filtering, search, and the canvas network visualization.
- `robots.txt`, `sitemap.xml`, `llms.txt`, `humans.txt`, and `site.webmanifest` support discovery and deployment.

## SEO notes

The current canonical URL is `https://steven-matrix.github.io/`. If the site is deployed under another GitHub Pages path or a custom domain, update the canonical URL, sitemap URL, robots sitemap line, Open Graph URL, and JSON-LD URLs.
